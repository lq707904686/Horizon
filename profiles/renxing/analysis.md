# 评估目标

判断这条资讯是否值得「人性台账」公众号在未来 24–72 小时内跟进，
能否改写成一篇有爆款潜力的选题。满分 10 分。
**先过五道闸门（见 match.md），任一不过直接给 0–2 分，不看热度。**
热度只决定它进不进候选池，不决定分。

# 评分标准（五维，每维 0–2 分，闸门全过才打分）

v1.7 改动：四维改五维。旧四维里"母题强度"和"大实话潜力"互相重叠，
且"证据是否可验证"没有单独维度，导致标题级信息也能冲高分。
新五维每一维都对应一个 8.0 选题的必要条件，五维全强才是 8+。
**五维是指导分不是加法**：总分由五维综合判断，8 分 = 五维接近拉满，
9–10 分只给五维全部满分且无任何保留的选题；不要把各维满分直接相加当总分。

| 维度 | 满分 | 打分要点 |
|---|---|---|
| **证据** | 2 | 事实是否可验证：有具体的人 + 动作 + 数字，有可查的信源（官方通报/原始报道/热搜排名与热度）。只有标题和导语、无核实细节得 0–1；人、数、来源齐全得 2 |
| **机制** | 2 | 是否揭示制度/结构性原因，而非个人恩怨：考核指标、分配规则、权力结构、商业模式。能点出"规则是谁写的、代价谁付的"得 2；只停留在个人故事得 0–1。命中母题库（见 ip-filter.md）深母题越多越好：分权/既得利益/甩锅/分钱/信任 |
| **决策** | 2 | 读者能做的具体决定。越具体（做什么 / 不做什么 / 什么时候做）、越多读者面临、越痛，分越高。能说出"读者读完能做什么决定"得 2；只有情绪共鸣没有决策抓手得 0 |
| **张力** | 2 | 冲突是否真实强烈：有真人受害、有极端后果（被辞退、轻生、立案、跑路）、有身份反差。真人 + 极端后果齐全得 2；只有结构观察、无受害者得 0–1 |
| **金句** | 2 | 能否产出 ≤20 字 S 级金句（功能见 ip-filter.md：数字冲击/角色错位/时间对比/反直觉/身份反差/归因反转）。能直接想出一句立得住的判断得 2；只有方向、想不出一句立得住的话得 0–1；立不住 → 该维 0 分 |

- **9–10：必须跟进。** 五维全强，可直接套六公式出标题、金句立得住。
- **7–8：值得写。** 五维里至少四维强；情绪、反差、数字至少占一样。
- **5–6：可作素材。** 有一定新意但需与其他材料合并，或角度需要深挖才能成文。
- **3–4：低优先级。** 相关但平淡，改写价值低；或纯资讯、找不到人性抓手。
- **0–2：噪音。** 闸门未过、或无关领域、广告、标题党无实质。

**进 hotspots 的线：≥7 分。** 7 分以下不进 hotspots 代码块（可进简报素材区）。

# 三条封顶规则（先按五维打分，再取低者）

封顶是硬性的，与维度分取低值；reason 里必须写明触发了哪条封顶。

1. **标题级封顶 6 分**：只有标题 / 导语级信息，没有核实细节（无具体人物、无
   数字来源、无一手信源），再热闹也不超过 6 分。
2. **未证实封顶 7 分**：关键事实未证实——遗书真实性、核心数字来源、官方未回应、
   当事人单方面说法——不超过 7 分，直到证实或官方回应。
3. **纯观点封顶 6 分**：纯观点、评论、判断，没有真实案例与人物（例如"出海错觉"
   这类只有观点的文章），不超过 6 分。

# 视频分 video_score（双分制，与公众号 score 并行）

video_score 只回答"这条资讯拍成 60–90 秒视频号值不值得拍"，不回答"公众号值不值得写"。
它与公众号 score 是两个独立的量纲：score 0–10 分，video_score 0–12 分，各打各的：不因 score 高而加分，不因 score 低而扣分。

| 分项 | 满分 | 打分要点 |
|---|---|---|
| **钩子张力** | 4 | 3 秒内能否抛出真人冲突或数字反差。开场即真人 + 极端后果 / 强反差数字得 4；其一突出得 3；冲突 / 反差存在但需铺垫得 2；弱得 1；无冲突无反差得 0 |
| **身份代入感** | 2 | 能否让特定人群（打工人、家长、子女、求职者、小老板）觉得"这说的就是我"。覆盖面广的刚需人群得 2；特定小圈子得 1；旁观者题材得 0 |
| **情绪冲突** | 2 | 对立双方是否清晰、可站队、有持续情绪张力。双方对立 + 情绪高点多得 2；对立存在但偏理性得 1；单向陈述得 0 |
| **可视化** | 1 | 不依赖算式 / 财报 / 长解释，一句话 + 一个画面能否讲清。能得 1；半得 0.5；不能得 0 |
| **完播友好度** | 1 | 结论是否依赖长推导、有无明确收尾落点（金句 / 反转 / 行动句）。有明确落点得 1；有但弱得 0.5；开放式 / 无落点得 0 |
| **传播潜力** | 2 | 观众会不会转发 / 收藏。转发意愿 0–1（会不会把这条发给家人 / 朋友 / 同事，即“你看这个”测试：跨圈警示或全民相关得 1；特定大圈内转发得 0.5；无转发冲动得 0）+ 收藏意愿 0–1（有没有一个值得存下来的数字、方法或清单：明确可存的得 1；仅一个记忆点强的数字得 0.5；无得 0） |

- **总分 0–12 分**：五子维（钩子张力 4 + 身份代入感 2 + 情绪冲突 2 + 可视化 1 + 完播友好度 1）0–10 分 + 传播潜力 0–2 分，再减时效分（0 / −0.5 / −1，下限 0 分）。
- **传播潜力 0 分降级**：传播潜力 0 分的题，即使 video_score ≥ 7，也降级排后——排在本轮所有传播潜力 ≥ 1 的入选题之后。
- **时效分（减分项，R3）**：新闻锚的日期距本轮雷达运行日超过 72 小时扣 0.5 分，超过 7 天扣 1 分（两档不叠加，取高档）；锚点日期以新闻事件 / 官方回应 / 原始报道的日期为准，查不到锚点日期的不扣分（不得编造）。
- **拍片线：video_score ≥ 7 入选；7.0–7.4 入选但排后，≥ 7.5 优先。** 公众号进 hotspots 的线（≥ 7 分）只看 score，不看 video_score；拍片只看 video_score，不看 score。
- **三条封顶只约束公众号 score，不约束 video_score。** 雷达眼里的"事实瑕疵"可能是视频观众眼里的"冲突燃料"。video_score 高但 score 被封顶的条目，成片须按"传闻 / 待核实"口径处理：不坐实未证实数字，只拍冲突本身；video_reason 里注明。
- 视频反馈（tools/load_feedback.py 追加的 video_tag_scores 段）仅供 video_score 参考，权重 0.15、限幅 ±5，不参与 score、不推翻任何封顶；窗口内视频记录不足 20 条时该段为空，video_score 只按本节打分。

### 来源与分栏（R2：选题来源民生化）
- **商业科技源占比上限**：36氪、虎嗅、爱范儿等商业科技源，每轮 video_score ≥ 7 的入选题里占比不超过 1/3（按入选篇数计）；超限时只取其中 video_score 最高的、占比不超 1/3 的部分。
- **简报民生 / 财经分栏**：每轮简报按 topic_category 分栏列出，不再混排——民生栏在前、财经栏在后、其他栏最后；每栏内按 video_score 降序。topic_category 按内容判定：民生（打工、维权、消费、教育、医疗、家庭）、财经（公司、财报、股价、行业）、其他。

# 8.0 锚点（真实案例，打分时对照）

## 锚点 1：8.0《乡干部伤人潜逃 15 年还升了正科》（2026-11-05）
- 证据：2026 年 10 月 30 日曲阳县纪委透露，吕登第持刀伤人后潜逃 15 年，
  期间违规领取空饷 140 余万元，还从副科升为正科；多名乡党委责任人受处分，
  时任刑警队长因涉嫌滥用职权被取保候审。人、动作、数字、官方核实齐全。接近满分。
- 机制：一个人跑路 15 年还能领工资升职，不是他一个人钻空子，是一串人装睡；
  母题：甩锅 + 既得利益 + 信任。满分。
- 决策：遇到伤害先固定证据、走法律程序，别指望内部消化；带队伍先查谁在岗谁不在岗。满分。
- 张力：真人被捅伤，潜逃 15 年，极端后果明确。满分。
- 金句："跑的是一个人，装睡的是一串人。"立得住。满分。
- 五维接近拉满 → 8.0。注意：本案关键事实均有曲阳县纪委 10 月 30 日核实，
  不触发"未证实封顶 7 分"；法院判决细节与受处分具体人数未写入本锚点，
  成稿如需引用须另核原始报道，不得按热搜摘要补写。

## 锚点 2：8.0《休息日爬山 5 小时没回消息被辞退》（2026-11-02）
- 证据：休息日、爬山 5 小时、没回消息、被辞退——人、动作、数字、后果齐全。
- 机制：隐形加班制度把"随时在线"变成默认义务；母题：分权 + 信任。
- 决策：被辞退如何维权、隐形加班如何留证据。
- 张力：真人被辞退，极端后果明确。
- 金句："隐形加班摆上台面。"立得住。
- 五维全强 → 8.0。

## 对照：7.0《瑞幸单季赚 21 亿，老店却跌 11%》（2026-11-04）
- 证据强（单季利润 21 亿、同店跌 11%）、机制强（扩张 vs 存量失血）、
  决策强（加盟前先算同店回本周期）、金句方向清晰。
- 但张力只有 1 分：结构观察，没有受害真人，没有极端后果；金句 1 分弱
  （方向清晰，冲击稍弱）。五维里四维强、一维弱，综合 7.0。
- 缺张力就上不了 8。**没有真人受害，就没有 8.0。**

# 四个升分触发器（7.0 故事升 8.0 的信号）

同一事件出现以下任一新进展，按新事实重新打分，不受"已发酵降分"限制：

1. **官方介入**：主管部门、巡视组、警方、法院介入调查或回应。
2. **热度跃升**：冲上热搜高位，或热度出现量级变化。
3. **当事人新发声**：当事人实名发声、新证据（遗书、录音、聊天记录）出现。
4. **新后果 / 处理结果**：被辞退、立案、赔偿、整改、道歉等实质进展出现。

# 评估维度补充

1. **人性母题匹配度**：命中母题库的个数与强度（见 ip-filter.md）。
2. **决策具体性**：决策是否具体到"做什么 / 不做什么 / 什么时候做"。
3. **身份代入感**：能否让特定人群（打工人、小老板、带队伍的人、做销售的人）觉得"这说的就是我"。
4. **六公式可套用度**：痛点直击 / 反直觉反转 / 数字冲击 / 悬念留白 / 身份代入 / 损失厌恶，至少能套中几个。
5. **标题可产出度**：能否产出 ≤20 字标题，且含人称（"你"）/ 阿拉伯数字 / 具体场景至少其一，不许问号结尾。产不出 → 扣分。
6. **时效与回访**：热点刚起（上升期）加分；**无实质新进展的重复才降分**。
   同一事件出现升分触发器（见上）时不降分，按新进展重新打分；
   本条资讯本身含有新进展的，优先按 8.0 候选评估。

看职场：跳槽/留任、谈薪、站队、接活/拒活、离职时机；
带队伍：招人/裁人、分钱、授权、处理刺头；

做销售：谈判、逼单、维护客户、处理投诉；
去创业：入场/退出、融资、选赛道、找合伙人、止损。

## 金句功能（WORKFLOW v3.5 P18）
S 级金句 6 种功能：数字冲击 / 角色错位 / 时间对比 / 反直觉 / 身份反差 / 归因反转。
金句硬约束：≤20 字；必须是一句立得住的判断，不是感慨；立不住 → 选题不成立。

## 大可口吻 checklist（闸门 4 的判据）
说人话不端着；结论先行不绕弯；敢说难听的实话但必须可验证；
不说教（不说"你应该……"，说"现实是……"）；不煽情、不鸡汤、不正确的废话；
一句话要有具体的人 + 动作 + 数字。
