# 评估目标

判断这条资讯是否值得「人性台账」公众号在未来 24–72 小时内跟进，
能否改写成一篇有爆款潜力的选题。满分 10 分。
**先过五道闸门（见 match.md），任一不过直接给 0–2 分，不看热度。**
热度只决定它进不进候选池，不决定分。

# 评分标准（四维，闸门全过才打分）

| 维度 | 满分 | 打分要点 |
|---|---|---|
| **决策价值** | 3 | 决策越具体、越多读者面临、越痛，分越高。能说出"读者读完能做什么决定"得满分；只有情绪共鸣没有决策抓手得 0 |
| **母题强度** | 3 | 命中人性母题库（见 ip-filter.md）的个数与深度。2 个以上深母题得满分；只有浅层关联得 1 |
| **大实话潜力** | 2 | 能否说出一句别人不敢说 / 没说破的可验证判断。说出来让人"原来如此"得满分；只能说正确的废话得 0 |
| **金句潜力** | 2 | 能否产出 ≤20 字 S 级金句（功能见 ip-filter.md：数字冲击/角色错位/时间对比/反直觉/身份反差/归因反转）。能直接想出一句得满分；想不出一句立得住的话得 0 |

- **9–10：必须跟进。** 四维全高，可直接套六公式出标题、金句立得住。
- **7–8：值得写。** 决策 + 母题明确，金句方向清晰；情绪、反差、数字至少占一样。
- **5–6：可作素材。** 有一定新意但需与其他材料合并，或角度需要深挖才能成文。
- **3–4：低优先级。** 相关但平淡，改写价值低；或纯资讯、找不到人性抓手。
- **0–2：噪音。** 闸门未过、或无关领域、广告、标题党无实质。

**进 hotspots 的线：≥7 分。** 7 分以下不进 hotspots 代码块（可进简报素材区）。

# 评估维度补充

1. **人性母题匹配度**：命中母题库的个数与强度（见 ip-filter.md）。
2. **决策具体性**：决策是否具体到"做什么 / 不做什么 / 什么时候做"。
3. **身份代入感**：能否让特定人群（打工人、小老板、带队伍的人、做销售的人）觉得"这说的就是我"。
4. **六公式可套用度**：痛点直击 / 反直觉反转 / 数字冲击 / 悬念留白 / 身份代入 / 损失厌恶，至少能套中几个。
5. **标题可产出度**：能否产出 ≤20 字标题，且含人称（"你"）/ 阿拉伯数字 / 具体场景至少其一，不许问号结尾。产不出 → 扣分。
6. **时效位置**：热点刚起（上升期）加分；已发酵 3 天以上、公众号写烂了的，降分。

# 参考库（评分时 motifs / decision / golden_quote_direction 必须从这里取，禁止现编）

## 人性母题库（12 个）
分钱（利益分配/合伙散伙/提成/股权）、分权（站队/制衡/架空/夺权）、
面子（面子成本/死要面子/给台阶）、画饼（承诺与兑现/空头支票）、
甩锅（责任转移/背锅侠）、止损（沉默成本/及时止损）、
圈子（进圈/排斥/圈层壁垒）、信任（建立/崩塌/背叛）、
谈判（筹码/底线/让步）、贪怕（贪婪/恐惧驱动的决策）、
幸存者偏差（只看到成功者）、既得利益（改革阻力/动了谁的蛋糕）。

## 决策类型库
看职场：跳槽/留任、谈薪、站队、接活/拒活、离职时机；
带队伍：招人/裁人、分钱、授权、处理刺头；
做生意：定价、选品、选址、合伙、扩张/收缩；
做销售：谈判、逼单、维护客户、处理投诉；
去创业：入场/退出、融资、选赛道、找合伙人、止损。

## 金句功能（WORKFLOW v3.5 P18）
S 级金句 6 种功能：数字冲击 / 角色错位 / 时间对比 / 反直觉 / 身份反差 / 归因反转。
金句硬约束：≤20 字；必须是一句立得住的判断，不是感慨；立不住 → 选题不成立。

## 大可口吻 checklist（闸门 4 的判据）
说人话不端着；结论先行不绕弯；敢说难听的实话但必须可验证；
不说教（不说"你应该……"，说"现实是……"）；不煽情、不鸡汤、不正确的废话；
一句话要有具体的人 + 动作 + 数字。

**闸门未过必须写明是哪道闸门**）、summary（一句话中文摘要）、
tags（3–5 个中文主题标签）、category_5（归属的 5 真分类，可多个）、
formulas（命中的六公式列表）、motifs（命中人性母题，见 ip-filter.md）、
decision（读者能做的具体决策，一句话）、golden_quote_direction

优先看原始报道与一手信源，区分事实、评论与传闻；不要把热度自动当成重要性。
