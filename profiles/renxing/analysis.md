# 评估目标

判断这条资讯是否值得「人性台账」公众号在未来 24–72 小时内跟进，
能否改写成一篇有爆款潜力的选题。满分 10 分。

# 评分标准

- **9–10：必须跟进。** 强人性母题（命中 5 真分类至少 1 个：看职场/带队伍/做生意/做销售/去创业）
  ＋强情绪（痛点/焦虑/愤怒/共鸣/损失感）＋反常识或有硬数字，可直接套六公式出标题。
- **7–8：值得写。** 有明确的人性/商业判断角度，改写后可成选题；情绪、反差、数字至少占一样。
- **5–6：可作素材。** 有一定新意但需与其他材料合并，或角度需要深挖才能成文。
- **3–4：低优先级。** 相关但平淡，改写价值低；或纯资讯、找不到人性抓手。
- **0–2：噪音。** 无关领域、广告、标题党无实质。

# 评估维度（打分依据）

1. **人性母题匹配度**：命中 5 真分类（看职场/带队伍/做生意/做销售/去创业）的个数与强度。
2. **情绪浓度**：是否戳中具体痛点（钱、面子、安全感、被辜负、不公平）。
3. **反常识度**：是否与大众常识相反，有认知落差。
4. **数字与具体性**：有无硬数字、具体人物、具体场景（"数字冲击"公式的弹药）。
5. **身份代入感**：能否让特定人群觉得"这说的就是我"。
6. **六公式可套用度**：痛点直击/反直觉反转/数字冲击/悬念留白/身份代入/损失厌恶，至少能套中几个。

# 输出要求

返回 JSON：score（0–10 数字）、reason（2–3 句中文，讲清加分/扣分点）、
summary（一句话中文摘要）、tags（3–5 个中文主题标签）、
category_5（归属的 5 真分类，可多个）、formulas（命中的六公式列表）。
优先看原始报道与一手信源，区分事实、评论与传闻；不要把热度自动当成重要性。
