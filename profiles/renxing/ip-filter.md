## 一、人性母题库（12 个，评分 motifs 字段取值范围）

| 母题 | 含义 | 典型场景 |
|---|---|---|
| 分钱 | 利益分配、合伙散伙、提成、股权 | 合伙人分账不均、提成规则改了 |
| 分权 | 站队、制衡、架空、夺权 | 新领导空降、老人被架空 |
| 面子 | 面子成本、死要面子、给台阶 | 为了面子接亏本单、谈判桌上给对方面子 |
| 画饼 | 承诺与兑现、空头支票 | 老板画饼不兑现、期权变废纸 |
| 甩锅 | 责任转移、背锅侠 | 项目黄了找人背锅、出了事往下推 |
| 止损 | 沉默成本、及时止损 | 亏本生意舍不得关、烂关系舍不得断 |
| 圈子 | 进圈、排斥、圈层壁垒 | 进不了核心圈、被排挤出局 |
| 信任 | 建立、崩塌、背叛 | 合作多年被合伙人坑、客户突然翻脸 |
| 谈判 | 筹码、底线、让步 | 谈薪、谈价、谈条件时的筹码博弈 |
| 贪怕 | 贪婪、恐惧驱动的决策 | 贪便宜踩坑、怕错过而跟风 |
| 幸存者偏差 | 只看到成功者 | 只看到赚钱的店，看不到倒闭的店 |
| 既得利益 | 改革阻力、动了谁的蛋糕 | 改革推不动，因为动了老人的利益 |

## 二、决策类型库（decision 字段取值方向）

- 看职场：跳槽 / 留任、谈薪、站队、接活 / 拒活、离职时机
- 带队伍：招人 / 裁人、分钱、授权、处理刺头、开人谈话
- 做生意：定价、选品、选址、合伙、扩张 / 收缩、清库存
- 做销售：谈判、逼单、维护客户、处理投诉、报价策略
- 去创业：入场 / 退出、融资、选赛道、找合伙人、止损

## 三、金句功能配比（WORKFLOW v3.5 P18，golden_quote_direction 参考）

S 级金句的 6 种功能，单篇选题至少能产出其中 1 种才算有金句潜力：
数字冲击 / 角色错位 / 时间对比 / 反直觉 / 身份反差 / 归因反转。

金句硬约束：≤20 字；必须是一句立得住的判断，不是感慨；
立不住 → 选题不成立（WORKFLOW v3.5 §0.5：金句逐字来自正文，雷达阶段先验方向）。

## 四、大可口吻 checklist（闸门 4 的判据）

- 说人话，不端着；结论先行，不绕弯
- 敢说难听的实话，但必须可验证（有数字、有人、有场景）
- 不说教：不说"你应该……"，说"现实是……"
- 不煽情、不鸡汤、不正确的废话
- 一句话要有具体的人 + 动作 + 数字（WORKFLOW v3.5 §C 内容层铁律）
